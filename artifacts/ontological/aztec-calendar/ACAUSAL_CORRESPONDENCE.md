# Mexica calendrical systems / Sun Stone

## Acausal correspondence

No bijection exists between a 260-state cycle and 12 states. A group homomorphism to Z/12Z has image size dividing gcd(260,12)=4.

## Mathematical model

Model: define a source-native finite state set S, operations T, and candidate map f:S→C12 or a stated alternative. This defines a research obligation, not an established source isomorphism.

## Correspondence tests

Check domain/codomain sizes, injectivity, surjectivity, inverse and f(T(s))=U(f(s)); preserve failed cases. Shared numbers alone fail this test.
